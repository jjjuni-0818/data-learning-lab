# Data Learning Lab

비전공자를 위한 Python 데이터분석 · 시각화 · 데이터베이스 학습 프로그램

## 목표
Python(Pandas) 데이터 분석, 시각화, DB 활용을 비전공자도 쉽게 배울 수 있도록,
데이콘보다 진입장벽을 낮춘 실습 + 자동채점 + 정답해설 형태의 학습 콘텐츠를 제작합니다.

## 진행 방식
1. 노트북(Jupyter/Colab) 기반으로 콘텐츠 제작 (1인 학습용으로 시작)
2. 각 챕터: 개념 설명 → 예제 → 실습 → 자동 채점 → 힌트 → 정답 해설
3. 콘텐츠 완성 후 필요 시 웹 서비스로 확장 검토

## 커리큘럼
- 0. 환경설정
- 1. Pandas 데이터 분석
- 2. 데이터 시각화
- 3. DB / SQL 활용
- 4. 종합 프로젝트
