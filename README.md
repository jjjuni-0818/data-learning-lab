# Data Learning Lab

비전공자를 위한 Python 데이터분석 · 시각화 · 데이터베이스 학습 웹앱

## 목표
Python(Pandas) 데이터 분석, 시각화, DB 활용을 비전공자도 쉽게 배울 수 있도록, 데이콘보다 진입장벽을 낮춘 실습 + 자동채점 + 정답해설 형태의 학습 서비스를 만듭니다. 회원가입, 학습 진행률 저장, 브라우저 내에서 직접 코드 작성·실행, 단원별 초급/중급/고급 복습까지 지원하는 실제 동작하는 웹앱으로 개발합니다.

## 기획 자료
전체 커리큘럼 플로우, 자동채점 구조, 화면 와이어프레임 등은 별도 기획 캔버스에 정리되어 있습니다.

## 앱 플로우

### 전체 플로우
```mermaid
flowchart TD
    A[랜딩 페이지] --> B{로그인 상태?}
    B -- 아니오 --> C[회원가입 / 로그인]
    C --> D[대시보드<br/>전체 진행률 확인]
    B -- 예 --> D
    D --> E[모듈 선택<br/>1.데이터 표현 이해 ~ 3.DB 기초]
    E --> F[챕터 선택]
    F --> G[챕터 학습 진행<br/>아래 상세 플로우 참고]
    G --> H{모듈 내 챕터<br/>모두 완료?}
    H -- 아니오 --> F
    H -- 예 --> I[모듈 완료<br/>다음 모듈로]
    I --> E
```

### 상세 플로우 — 챕터 하나의 학습 흐름
```mermaid
flowchart TD
    A[챕터 진입] --> B[개념 설명 읽기]
    B --> C[예제 코드 실행해보기]
    C --> D[초급 문제 풀기<br/>코드 에디터 작성]
    D --> E[채점하기 클릭]
    E --> F{정답과 일치?}
    F -- 아니오 --> G[힌트 열람 후 재시도]
    G --> D
    F -- 예 --> H[초급 통과<br/>진행률 저장]
    H --> I[중급 문제 풀기]
    I --> J{정답과 일치?}
    J -- 아니오 --> K[힌트 열람 후 재시도]
    K --> I
    J -- 예 --> L[중급 통과<br/>진행률 저장]
    L --> M[고급 문제 풀기]
    M --> N{정답과 일치?}
    N -- 아니오 --> O[힌트 열람 후 재시도]
    O --> M
    N -- 예 --> P[고급 통과<br/>정답 해설 확인]
    P --> Q[챕터 완료<br/>다음 챕터로]
```

## 기술 스택
| 영역 | 사용 기술 |
|---|---|
| 프론트엔드 | React + TypeScript (Vite) |
| 회원가입/로그인 · DB | Supabase (Auth + Postgres) |
| 코드 에디터 | Monaco Editor (연결 검증 완료) |
| 코드 실행 · 채점 | Pyodide — 브라우저에서 Python 실행 (연결 검증 완료) |
| 배포 | Vercel / GitHub Pages *(예정)* |

## 커리큘럼
총 3개 모듈, 15개 챕터로 구성됩니다. 각 챕터는 초급 → 중급 → 고급 3단계로 복습하며,
각 단계마다 여러 개의 실습 문제를 풀어야 다음 단계가 열립니다.

**1. 데이터 표현 이해** (선형대수 · 함수 · 통계 감각)
1. 벡터와 행렬로 데이터 표현하기
2. 가중합과 계산 이해하기
3. 함수와 그래프 이해하기
4. 데이터 요약과 통계

**2. 데이터 시각화** (Pandas + Matplotlib/Seaborn + 프로젝트)
1. DataFrame이란? *(완성)*
2. 데이터 불러오기와 정제
3. 데이터 탐색과 분석
4. 데이터 시각화
5. 프로젝트 기반 학습 (헬스케어 미니 프로젝트)

**3. 데이터베이스(DB) 기초** (SQL + Python 연동 + ORM + NoSQL)
1. 데이터베이스 기본 개념 이해
2. SQL 기초 및 데이터 조회
3. Python + DB 연동 경험
4. ORM(SQLAlchemy)과 모델링
5. NoSQL(MongoDB) 이해와 활용
6. 프로젝트 기반 실습

## 로컬 실행 방법
```bash
npm install
npm run dev
```

Supabase 연결을 위해 프로젝트 루트에 `.env` 파일이 필요합니다 (`.env`는 git에 포함되지 않습니다):
```
VITE_SUPABASE_URL=...
VITE_SUPABASE_PUBLISHABLE_KEY=...
```
